# Gestor de Tareas por Proyecto

Aplicacion web para gestionar tareas por proyecto.

## Requisitos

- Node.js 20 o superior
- npm 10 o superior

## Backend

1. Entrar a `backend`
2. Instalar dependencias con `npm install`
3. Levantar el entorno de desarrollo con `npm run dev`

El backend queda disponible en `http://localhost:3001` y expone `GET /api/health`.

## Frontend

1. Entrar a `frontend`
2. Instalar dependencias con `npm install`
3. Levantar el entorno de desarrollo con `npm run dev`

El frontend queda disponible en `http://localhost:5173` y consulta el backend usando `/api/health`.
